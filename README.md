# Pomodoro Game

Gamified pomodoro timer originally built as a class project,
now being expanded into a more complete productivity game with,
task tracking and progression systems.

## Features

- Pomodoro timer with custom work / break cycles
- Task list management
- Stats and achievement tracking

## Status

Currently refactoring from a course assignment into a standalone project.

## Roadmap

- Refactor codebase and file structure
- Improve persistence and save system
- Add achievements
- Add stat tracking (total time/sessions, longest session, streaks, etc.)
